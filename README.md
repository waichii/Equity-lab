# Equity 練習簿（離線版）

## 放上 GitHub Pages
1. 喺 GitHub 開一個新 repo（例如 `equity-lab`），或者喺你現有 GitHub Pages repo 開一個 `equity-lab/` 資料夾。
2. 將呢個資料夾入面所有檔案上載上去。
3. Repo 嘅 Settings → Pages，揀 branch 做來源。
4. 用 iPhone Safari 開條網址，撳「分享」→「加入主畫面」。
5. 開一次之後，就算冇網都可以喺主畫面打開。

## 更新
改完 `index.html` 之後，記得將 `sw.js` 入面 `VERSION` 改大一號（例如 v2），手機下次有網開嘅時候就會攞新版本。

## 電腦
直接雙擊 `index.html` 用瀏覽器開都得，唔使上網。
